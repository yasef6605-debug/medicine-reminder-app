# 💊 تطبيق إدارة الأدوية الذكي

تطبيق موبايل متقدم لإدارة ومتابعة الأدوية مع منبهات ذكية وتقارير شاملة.

## ✨ المميزات الرئيسية

### 📋 إدارة الأدوية
- ✅ إضافة أدوية بمعلومات كاملة (الاسم، النوع، الشكل، الجرعة)
- ✅ تحديد مواعيد التناول (قبل/بعد الطعام)
- ✅ مراقبة المخزون والتنبيه عند نفاده
- ✅ تعديل وحذف الأدوية
- ✅ تاريخ انتهاء الصلاحية

### 📷 مسح الباركود
- ✅ مسح باركود علبة الدواء
- ✅ استخراج اسم الدواء تلقائياً
- ✅ ملء البيانات الأساسية بسرعة

### 🔔 المنبهات الذكية
- ✅ منبهات ذكية مع رنين وهتزاز
- ✅ تنبيهات ناطقة باسم الدواء
- ✅ تعمل حتى لو كان التطبيق مغلقاً
- ✅ ت��بيه قبل 5 دقائق من الموعد
- ✅ توقف تلقائي للتنبيه عند تناول الدواء

### 📊 التقارير والإحصائيات
- ✅ نسبة الالتزام اليومية/الأسبوعية/الشهرية
- ✅ رسوم بيانية وجداول توضيحية
- ✅ تكلفة الأدوية المتناولة
- ✅ تتبع الميزانية الصحية

### ⚠️ تحذيرات التفاعلات الدوائية
- ✅ تنبيه عند إضافة أدوية متفاعلة
- ✅ عرض معلومات التفاعلات
- ✅ نصائح الأمان الدوائي

### 🏥 معلومات طبية شاملة
- ✅ قاموس الأدوية المتقدم
- ✅ الاستخدامات والآثار الجانبية
- ✅ موانع الاستعمال
- ✅ نصائح عند تناول الدواء
- ✅ سجل طبي شخصي

### 👨‍⚕️ ميزات التواصل
- ✅ مشاركة التقارير مع الطبيب/الأسرة
- ✅ قائمة الاتصال الطارئة
- ✅ معلومات الصيدليات والمراكز الطبية

### 👥 ملفات العائلة
- ✅ إنشاء ملفات متعددة للعائلة
- ✅ إدارة أدوية عدة أفراد
- ✅ تنبيهات منفصلة لكل شخص

### 🎨 تخصيص التطبيق

### 🔐 الأمان والخصوصية

## 🛠️ المتطلبات التقنية

- Flutter SDK 3.0.0 أو أحدث
- Dart 3.0.0 أو أحدث
- Android 6.0+ أو iOS 11.0+

## 📦 التثبيت

```bash
# استنساخ المستودع
git clone https://github.com/yasef6605-debug/medicine-reminder-app.git

# الدخول للمجلد
cd medicine-reminder-app

# تثبيت المكتبات
flutter pub get

# تشغيل التطبيق
flutter run
```
